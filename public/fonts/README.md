# Inspecta typography

These unmodified Latin web fonts are served locally so the interface and fixture demo need no external font requests. Other characters use the system fallback fonts.

- **Doto**: pixel headings and wordmark, weight 800. [Upstream](https://github.com/oliverlalan/Doto). License: `Doto-OFL.txt`.
- **IBM Plex Sans**: readable body copy and investigation notes, weights 400–600. [Upstream](https://github.com/IBM/plex). License: `IBM-Plex-Sans-OFL.txt`.
- **IBM Plex Mono**: navigation, labels, controls, source code and commit references, weights 400 and 500. [Upstream](https://github.com/IBM/plex). License: `IBM-Plex-Mono-OFL.txt`.

Retrieved from the Google Fonts CSS service for the 2026-10-03 interface update. The accompanying SIL Open Font License files are preserved from the [Google Fonts repository](https://github.com/google/fonts).
